Supabase Cloud Database Setup

Scribble Arena uses Supabase to store active rooms, match archives, custom word packs, and global player leaderboards.

Quick 2-Step Activation:
1. Open supabase_setup.sql in your project folder and run it in your Supabase SQL Editor.
2. Copy your Project URL and Anon Key into the .env file: 
SUPABASE_URL=https://your-project.supabase.co
SUPABASE_ANON_KEY=eyJhbGciOi...

Game Server Connection

Scribble Arena uses Socket.IO WebSockets for synchronized multiplayer drawing, countdowns, and room state.

Deployment Guide:
• Render.com / Railway / Cloud VPS: Supports WebSockets out-of-the-box! Leave blank if running on the same host.
• Custom Backend: If your server runs on a different port or remote domain, enter your backend URL below (e.g. https://your-scribble.onrender.com).
